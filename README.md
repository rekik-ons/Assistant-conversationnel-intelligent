# Assistant conversationnel intelligent – Taysir Microfinance

**Projet de fin d'études (PFA)**

## Présentation

Conception et développement d'un assistant conversationnel intelligent permettant de qualifier les prospects, d'évaluer leur profil et de répondre aux questions fréquentes.

Le projet repose sur une approche hybride combinant des règles métier, **Rasa** et l'intelligence artificielle générative.

## Technologies utilisées

- React
- Python
- FastAPI
- Rasa
- Qwen3 / Ollama
- SQLite

## Fonctionnalités

- Qualification automatique des prospects
- Collecte et validation des informations
- Calcul du score et classification des prospects
- FAQ intelligente
- Tableau de bord administrateur
- Exportation des données au format CSV

## Objectif

Faciliter la préqualification des prospects et améliorer leur orientation grâce à un assistant conversationnel intelligent.
