# Assistant-conversationnel-intelligent
Assistant conversationnel intelligent – Taysir Microfinance  Projet de fin d'études (PFA)  Conception et développement d'un assistant conversationnel intelligent permettant de qualifier les prospects, d'évaluer leur profil et de répondre aux questions fréquentes grâce à une approche hybride combinant règles métier, Rasa et IA générative.
