 # Assistant conversationnel intelligent – Taysir Microfinance

Projet de fin d'études (PFA)

Conception et développement d'un assistant conversationnel intelligent permettant de qualifier les prospects, d'évaluer leur profil et de répondre aux questions fréquentes grâce à une approche hybride combinant règles métier, Rasa et IA générative.

Technologies :
- React
- Python / FastAPI
- Rasa
- Qwen3 / Ollama
- SQLite
  
Fonctionnalités :
- Qualification automatique des prospects.
- Collecte et validation des informations.
- Calcul du score et classification des prospects.
- FAQ intelligente.
- Tableau de bord administrateur.
- Exportation des données en CSV.
